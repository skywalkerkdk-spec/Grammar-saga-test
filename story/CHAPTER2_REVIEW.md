# Chapter II 통합 구현 검토

기준 스토리 브랜치 커밋은 `29eee0e`입니다. 작업 시점의 `main` 게임 HTML과 스토리 브랜치의 기존 게임 HTML 차이는 Chapter II 로딩 태그 2줄이었습니다. 구현은 별도 `implementation/chapter2-complete` 브랜치에서 검토합니다.

## 구현 및 기존 코드와의 접점

| 구간 | 연결 방식 |
|---|---|
| 오프닝과 마을 | 기존 세계 지도 개방 조건을 사용합니다. 18개 마을과 72명은 던전 ID와 주민 인덱스로 연결합니다. v1.1 명칭은 Chapter II에서 표시합니다. |
| 특별 퀘스트 | 기존 교정 문제와 던전 클리어 기록으로 단서 잠금을 판단합니다. 수집·답·완료는 `SV.specialQuests`에 있습니다. 정답 풀, 수정, 골드, 페이지 보상 조건에는 특별 퀘스트가 개입하지 않습니다. |
| 대도서관 | 기존 세계 지도에서 들어가는 별도 메뉴 허브입니다. 그라마티카 복원실, 문법 자료실, 세계관 도감, 몬스터 도감, 모험 일지, 비밀 기록실이 있습니다. 기존 `d16`은 별도 던전입니다. |
| 등록과 복원 | 페이지 등록은 기존 `SV.chapter2.episodes`에 기록합니다. 복원 이벤트는 읽지 않은 기록을 낮은 단계부터 열며, 읽은 기록은 다시 볼 수 있습니다. 노바의 선택 기록은 기존 `d16` 클리어로 엽니다. |
| 컷신과 동료 | 마을 방문·회복·특별 퀘스트 해결 상태에 따라 장면을 여는 버튼을 표시합니다. 보스 장면은 기존 보스 대화에 연결합니다. 8명의 동료 기록은 기존 파티 ID에 연결되며, 해당 동료의 유무가 메인 진행에 영향을 주지 않습니다. |
| 최종 던전 | 새 ID `sanctuary_of_silence`를 사용합니다. 18개의 등록된 페이지를 요구합니다. 기존 학습 전투 엔진이 4단계에 걸쳐 각 영역 한 문제씩 출제합니다. 일반 던전 목록에 별도 항목을 끼워 넣지 않았습니다. 진행 중인 다른 던전의 이어하기 기록을 보호합니다. |
| 엔딩 | 최종 전투 후 사일렌티우스 엔딩과 `Guardian of Language` 칭호를 엽니다. 시나리오 전용 전투에서 수정·강화석·랭킹 보상은 지급하지 않습니다. Chapter III `The Forgotten Words`는 에필로그 복선입니다. |

## 리소스와 편집 검토

- 대도서관은 6개 메뉴 시설입니다. 걸어 다니는 도서관 지도와 렉시온 전용 스프라이트는 패키지에 없습니다.
- 마을 장면, 사일렌티우스 전투, 엔딩에는 기존 배경과 스프라이트를 사용합니다. 마을별 컷신 그림과 이펙트, 성역 배경, 사일렌티우스 전용 디자인과 음향은 별도 제작 대상입니다. 사일렌티우스의 현재 전투 스프라이트는 `d18`의 기존 보스 스프라이트입니다.
- 18개 지역의 최종 문제는 기존 문제은행과 난이도 선택을 사용합니다. 실제 학생 플레이에서의 난이도와 소요 시간은 검토가 필요합니다. 성역은 학습 모드 전투로 구현했습니다.
- 문법 자료실 한국어 예문은 초벌 직독직해입니다. 해당 화면에서는 자연스러운 해석 모드를 제공하지 않습니다. 확장 대화의 단일 의미 단위와 특별 퀘스트 선택지의 영어 표기는 원본 데이터를 유지했습니다. 전체 영문·국문 편집과 학생 대상 언어 검수는 별도 검토 대상입니다.
- 전체 데이터 509줄의 영어 청크가 영어 원문과 일치하는 것을 기계적으로 확인했습니다. 의미 대응, 자연스러움과 학습 난도에 대한 전수 편집 검수는 별개입니다.

## 검증 방식

저장·입장 조건은 모바일 Chromium에서 테스트용 계정과 기존 학습·RPG 클리어 기록을 구성해 확인했습니다. 최종 성역은 기존 전투 UI로 18문제를 모두 진행했습니다. 운영 저장 계정이나 GitHub Pages에는 테스트 데이터를 적용하지 않았습니다.
