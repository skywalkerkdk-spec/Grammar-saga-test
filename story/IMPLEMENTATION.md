# Codex 구현 지침 — 신규 제안
STORY_DATA.json을 스토리 데이터로 읽고 STORY_SCRIPT.md를 검토용으로 사용한다. ORIGINAL_TOWN_SOURCE.txt는 과거 원본 참고용이며 최신 코드에 덮어쓰지 않는다.

- 기본 표시: 영어 / 직독직해. chunks 배열의 같은 인덱스에 palette 색상을 적용한다. 자연스러운 해석 모드에서는 en과 ko를 표시하고 영어 전용 모드에서는 en만 표시한다. 색상 끄기, 슬래시 표시, 설정 저장을 지원한다. 오류 강조는 기존 문제 UI에 한정한다.
- 신규 대도서관 안전 지역과 렉시온은 기존 d16 던전 및 노바와 별개다. 노바의 대출 카드는 선택적 비밀 기록 해금용이며 필수 진행 조건이 아니다.
- 기존 d6/d7/d8 학습 클리어 조건을 유지한다. 신규 스토리 방문 및 페이지 등록은 기존 던전 개방에 영향을 주지 않는다. cj/d7/d8에는 신규 마을 페이지를 부여하지 않는다.
- 각 episode의 id는 기존 던전 ID와 같다. 주민은 index로 기존 TOWN[id].n[index]에 연결하고 이름도 대조한다. 기존 b/f/o/th 및 보상은 변경하지 않는다. 신규 before_problem은 저주에 대한 설명용 정상 영어 예시이며 기존 오류 대사를 대체하지 않는다. after_recovery는 개별 정답 또는 던전 클리어 후 표시한다.
- 신규 저장 상태는 기존 SV.town과 분리한다. accepted, rewardClaimed, registered, seenEvents를 마을별로 저장한다. 기존 던전 학습/RPG 클리어 판정을 재사용한다. 개별 교정은 선택 사항이며 기존 수정 보상만 지급한다. 던전 클리어 후 대표 주민 대화에서 페이지 및 기념품을 한 번 지급한다. 기존 클리어 사용자도 재전투 없이 완료 가능해야 한다.
- next_id는 권장 순서이지 잠금 조건이 아니다. 선행 마을을 건너뛴 경우 연결 대사는 선행 사건을 이미 경험했다고 단정하지 않도록 생략하거나 조건부 표시한다. 기록/편지/인장 등 연결 소품은 스토리 플래그로 처리 가능하며 필수 인벤토리 아이템이 아니다. 보상은 능력치 없는 기념품으로 우선 구현한다.
- 도서관 등록 수 3/6/9/12/15/18에서 milestone 이벤트를 한 번씩 표시한다. 특정 사건을 아직 경험하지 않았다면 도서관의 독립 조사 결과로 표현한다. 18개 등록 시 신규 최종 던전 침묵의 성역을 제안하되 기존 콘텐츠는 그대로 유지한다. 사일렌티우스는 쿠키 영상 화자 후보이며 신규 설정이다.
- TTS는 정상 영어 문장만 기본 재생한다. 음성 API가 없으면 재생 버튼을 비활성화한다. 스킵과 다시 보기 지원. 모바일에서 긴 문장은 줄바꿈을 허용한다.
- 검증: 기존 저장 불러오기, 학습/RPG 각각의 클리어, 개별 교정 보상 중복 방지, 페이지 중복 방지, 역순 방문, 18개 등록, 모드 전환 및 모바일 가독성.

이 패키지는 스토리 초안 및 데이터 명세이며 실제 게임 코드 변경이나 런타임 테스트를 포함하지 않는다. 영문 마을명은 신규 대사에서 쓰는 임시 표기이며 기존 공식 영문명이 아니다. 기존 지도 영문명은 유지한다. 보스 전후 공통 대사는 추후 개별 연출로 확장 가능하다.

## v1.1 명칭 통일 (우선 적용)
NAMING_REGISTRY.json과 STORY_DATA.json v1.1을 명칭의 기준으로 사용한다. STORY_SCRIPT.md 및 ORIGINAL_TOWN_SOURCE.txt는 이전 버전 참고 자료이며 명칭이 충돌하면 v1.1을 우선한다. 기존 주민 연결 시 name_legacy 및 index, 마을은 town_legacy 및 id, 보스는 boss_legacy를 사용한다. 표시명은 name_en, town_en, boss_en, speaker_en 등 영문 필드를 우선하고 한국어 표기를 병기한다. 기존 문제 본문, 내부 ID, 저장 키는 변경하지 않는다. 기존 몬스터 개별 이름과 Chapter I 명칭은 이번 변경 범위 밖이다. 실제 UI 및 기존 게임 소스에 적용할 때 남은 이전 이름 참조를 검토한다.
